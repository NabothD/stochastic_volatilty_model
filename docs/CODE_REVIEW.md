# Review of the original thesis code

This note lists the problems found in the original scripts (now in
`legacy/python/`) and how the new `svuq` package deals with each one. Line
numbers refer to the files in `legacy/python/`. Equation and section numbers
refer to the thesis.

Severity:
- **High**: changes results qualitatively.
- **Medium**: biases results or estimates.
- **Low**: hygiene or reproducibility.

## 1. Parameter estimation (MCMC + SIR)

| # | Severity | Where | Problem | Fix in `svuq` |
|---|---|---|---|---|
| 1.1 | High | `New_code_Heston_v_6.py:160` | The particle cloud is initialised once, before the MCMC loop. Every later sweep starts its filter from the cloud left at the *last* time step of the previous sweep, not from a draw of `V_0`. | The cloud is re-drawn at t=0 on every sweep, from the stationary CIR law or a user prior on `v0` (`ParticleFilter.initial_particles`). |
| 1.2 | High | `New_code_Heston_v_6.py:184,207`, `New_code_Heston_Jumps_v_7.py:29–35` | The same return `R_k` is used twice: once to propagate the particle (the correlated shock) and again to weight the *propagated* particle. The observation is double-counted and the timing is off: `R_k` is generated by `V_{k-1}`, not `V_k`. | Particles of `V_{k-1}` are weighted by `p(R_k \| V_{k-1})`, resampled, then propagated to `V_k` with the shock implied by `R_k`. For this Euler scheme that is the fully adapted filter. |
| 1.3 | High | `New_code_Heston_v_6.py` (whole script), `New_code_Heston_Jumps_v_7.py` | The filtered **mean** path is used as if it were the true variance in the regressions. Two consequences. (a) That path is much smoother than the real one, so `sigma` is biased low. (b) Its increments are mostly the `rho`-correlated propagation term, so the `rho` regression feeds on its own output and drifts towards ±1. With weakly informative priors this chain diverges (see `tests` and the README experiment). It probably explains the S&P 100 estimates `rho = -0.96` (Heston) and `-0.93` (Bates). | Default `path="ffbs"`: a variance trajectory is drawn by forward-filter backward-sampling, so the regressions see realistic increments. `path="mean"` is kept to reproduce the thesis, with a warning. |
| 1.4 | High | `New_code_Heston_Jumps_v_7_Real.py` priors, Table 3 | The vol-of-vol prior `sigma^2 ~ IG(a, b)` uses `a = 149` (synthetic) and `a = 250` (real). That is worth about 300–500 observations. Its prior mean `sqrt(b/(a-1))` is 0.0130 (synthetic) and 0.0078 (real). The reported posteriors are 0.011 and 0.0074. **The data hardly moved `sigma` off its prior.** | `Priors.from_beliefs(..., sigma_strength=3)` gives weakly informative priors from interpretable beliefs. Posteriors can be checked against the prior. |
| 1.5 | Medium | `New_code_Heston_v_6.py:295–296` | The drift regression divides `R_k` by `sqrt(v_k)` (end of interval) instead of `sqrt(v_{k-1})`. | Index convention fixed in `ConjugateSampler.draw_mu`. |
| 1.6 | Medium | `New_code_Heston_v_6.py:382–412` | `beta` is drawn with the *previous* `sigma`, and `sigma^2` is drawn afterwards. | `sigma^2` is drawn from its marginal inverse-gamma posterior first, then `beta \| sigma^2` (an exact Normal–inverse-gamma draw). |
| 1.7 | Medium | `New_code_Heston_v_6.py:398–399` | Inadmissible `kappa` and `theta` are clipped to `1e-6`. This piles posterior mass on the boundary. | Rejection sampling: the prior is truncated to `0 < kappa < 1/dt`, `0 < theta < 4`. |
| 1.8 | Medium | `New_code_Heston_v_6.py:465` | The `omega` scale omits the prior term `tau0*psi0^2 - tau_n*m_n^2`, and the first residual row is a zero pad (so `n/2` is used instead of `(n-1)/2`). | Exact conjugate update in `ConjugateSampler.draw_rho`. |
| 1.9 | Medium | `New_code_Heston_v_6.py:805`, `..._Jumps_v_7.py` main | Precisions are written as `1/math.sqrt(sd**2)`, which equals `1/sd`, instead of `1/sd**2`. With `sd = 0.001` the drift prior was 1000× wider than Table 3 states. | `Priors` stores precisions explicitly and builds them as `1/sd**2`. |
| 1.10 | Low | thesis Eq. 70 | With `psi \| omega ~ N(psi0, omega/tau)`, the delta method needs `tau = w0^3 / (sd_rho^2 (psi0^2 + w0)^3)`. The thesis has `w0^2`. | Corrected in `Priors.from_beliefs`, with a unit test that samples the induced `rho` prior. |
| 1.11 | Low | all scripts | No burn-in: the reported means average over the initial transient. No convergence diagnostics. | `burn_in` parameter, effective sample size in `summary()`, trace plots. |
| 1.12 | Low | all scripts | The particle loop is pure Python over particles, and `refined_resample` does a linear search per particle, so the cost grows with the square of the particle count: 32.7 s per sweep with 1000 particles. | numba kernels: 44–85 ms per sweep, including backward sampling. Chains run in parallel processes (see the README Performance section). |

## 2. Bates-specific

| # | Severity | Where | Problem | Fix |
|---|---|---|---|---|
| 2.1 | High | `New_code_Heston_Jumps_v_7.py:223` | Jump indicators are drawn as `Bernoulli(lambda_jump_0)`. That is the *initial* value, never updated, and it is used as a per-step probability. With `0.16` that means about 40 jumps a year a priori. It should be `lam * dt` with the current `lam`. | `p_jump = lam * dt`, using the current draw. |
| 2.2 | High | `New_code_Heston_Jumps_v_7.py:230–231` | `V` and `Z` are resampled *separately*, with independent uniforms, so each volatility particle loses its own jump. `z_est` also averages the prior draws of particles that did not jump. | `(V, J, Z)` are resampled jointly. Jump-size statistics are conditional on `J = 1`. |
| 2.3 | High | `New_code_Heston_Jumps_v_7.py:227,246,278` | The jump-*adjusted* returns go into the filter, which also models jumps, so jumps are handled twice. The *raw* returns, jumps included, go into the `mu` and `rho` regressions. It should be the other way round. | The filter sees raw returns. The regressions see returns with the sampled jumps removed. |
| 2.4 | Medium | `New_code_Heston_Jumps_v_7.py:251` | `lam = sum_k P(J_k = 1)` is the expected **number** of jumps in the sample. It equals the annual intensity only when the sample is one year long. `parameter_samples_3y.csv` has a mean of 7.2 for 3 years of data. | `lam` is divided by the time span (moments mode), or drawn from `Gamma(a + #jumps, b + T)` (Gibbs mode, the default). |
| 2.5 | Medium | `New_code_Heston_Jumps_v_7.py:269` | `sigma_J` is computed from the spread of the per-step *posterior means*. With one or two jumps this collapses to about 0, as in Table 5 (0.0035) and Figure 7 (1e-5). | Gibbs mode draws `(mu_J, sigma_J^2)` from their Normal–inverse-gamma posterior given the sampled jump sizes. Moments mode includes the within-step variance. |
| 2.6 | Medium | `Bates_Euler_sim.py:19,81` | The synthetic Bates data use a log-Euler step with the jump compensator subtracted, but the estimator assumes the simple-return Euler step. The `mu` the estimator targets is therefore not the `mu` that was simulated. For `lam = 3`, `mu_J = -0.3` the compensator is about −0.73 a year, consistent with `mu ≈ -0.94` in `parameter_samples_3y.csv`. | `simulate(..., scheme="euler")` (the default) matches the estimator. `scheme="log"` is available and documented. |
| 2.7 | Low | filter | Jump particles are rare (`lam*dt ≈ 1%` of particles), so the jump-size posterior at a jump date rested on a handful of prior draws. | Importance proposal: `J` is proposed with probability ≥ 10%, and `Z` from a Gaussian informed by the return. The weights are corrected exactly. |

## 3. Option pricing and polynomial chaos

| # | Severity | Where | Problem | Fix |
|---|---|---|---|---|
| 3.1 | High | `scipy_to_chaospy` in every `New_code_*` file | The fitted `loc` (shift) of `lognorm`, `gamma` and `invgamma` is dropped. Consequences in `Chaospy_Heston.py:48–49`: `rho ~ Gamma(2.09, 0.0057)` has mean **+0.012**, against a posterior of −0.96, and `sigma ~ Gamma(11.19, 5.2e-5)` has mean 0.00058, against a posterior of 0.0074. The same happens in `Chaospy_Bates_Syn.py`, where `rho` has mean +0.18. **Option prices propagated through these distributions use the wrong sign of correlation.** | The mapping keeps `shift=loc`. Unit tests compare the chaospy and scipy moments for every family. |
| 3.2 | Medium | `fit_without_extremes(..., 2.5, 97.5)` | Marginals are fitted to samples with the tails trimmed, which understates the very uncertainty being propagated. | All samples are used by default (`trim=None`). |
| 3.3 | Medium | `Chaospy_*.py` | Independent marginals ignore posterior correlations (`kappa`–`sigma` correlation is about 0.7 in the tests). Orthogonal polynomials for shifted or truncated marginals are also numerically fragile. | The PCE is built on a standard-normal germ, using Hermite polynomials and an inverse-CDF map. An optional Gaussian copula keeps the correlations. It is validated against an exact posterior Monte Carlo (`uq.PosteriorPricer`) and reports a leave-one-out error. |
| 3.4 | Medium | thesis Eq. 53 | The Bates characteristic function is missing the compensator `-i u lam T (exp(mu_J + sigma_J^2/2) - 1)`, so as written it is not a martingale. QuantLib's `BatesEngine`, which the code used, includes it, so this is a documentation error. | `pricing.bates_cf` includes it. Tested: a call with `K -> 0` equals `S`. |
| 3.5 | Low | `Chaospy_Heston.py:12` | The maturity is `int(T*365)` days from `Date.todaysDate()`. That truncates and is not reproducible. | Native Lewis-formula pricer with exact `T`. It matches QuantLib to 1e-8 (tests), and QuantLib is now optional. |
| 3.6 | Low | `Chaospy_Heston.py:41` | `r = 0.2933` (a 29% risk-free rate) is hard-coded. It looks like a leftover from an experiment. | `r` is an explicit argument everywhere. |
| 3.7 | Low | `New_code_Heston_v_6.py` output | `Heston_Vols.xlsx` stores `Real` as a *variance* but `Final`/`Average` as `sqrt` (volatility), so they are not comparable. | Variance and volatility are kept separate and labelled. |

## 4. What stays the same

The structure of the method is unchanged:
- the Euler discretisation;
- the regression re-parametrisations (`eta`, `beta`, `psi`/`omega`);
- the conjugate priors;
- the SIR filter with refined, continuous resampling;
- the Gibbs alternation;
- PCE propagation.

Everything in the thesis can still be reproduced (`path="mean"`,
`jump_update="moments"`, `dependence="independent"`,
`Priors.thesis_synthetic()`).
